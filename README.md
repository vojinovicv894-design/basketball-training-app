# Basketball Training App 🏀

A personalized basketball training app designed to help athletes of all levels improve their skills with customized workout plans.

## Features

- **Personalized Training Plans**: Get custom workout routines based on your skill level and goals
- **Skill Tracking**: Monitor your progress across different basketball skills
- **Exercise Library**: Access hundreds of basketball drills and exercises
- **Workout History**: Keep track of completed workouts and achievements
- **Progress Analytics**: Visualize your improvements over time
- **Goal Setting**: Set and track short-term and long-term basketball goals

## Getting Started

### Prerequisites

- Node.js 16+ 
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/vojinovicv894-design/basketball-training-app.git
cd basketball-training-app
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

The app will open at `http://localhost:3000`

### Building for Production

```bash
npm run build
npm run preview
```

## Project Structure

```
src/
├── components/      # Reusable React components
├── pages/          # Page components
├── store/          # Zustand state management
├── types/          # TypeScript type definitions
├── utils/          # Utility functions
├── hooks/          # Custom React hooks
├── App.tsx         # Main app component
└── main.tsx        # Entry point
```

## Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Charts**: Recharts
- **HTTP Client**: Axios
- **Build Tool**: Vite
- **Routing**: React Router
